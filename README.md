# Round Logger

Personal training log for striking sports. No account. Sessions, exercises, and pad-work combinations stay in this browser.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Share links carry a snapshot of the workout in the URL, so another person can open the plan without a server. Short links such as `/share/s1` only resolve in a browser that already has that session stored locally.

The original v0 layout lives in `estrutura-do-round-logger` and is the visual reference for this app.
